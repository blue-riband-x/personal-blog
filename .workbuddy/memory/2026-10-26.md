- **github.com:443 直连中断、api.github.com 正常时**，可用 Git Data API 兜底推送：blob(utf-8/base64) → tree(base_tree+entries) → commit → PATCH ref。要让 API 建出的 commit SHA 与本地完全一致（免同步对象），必须：① blob 内容用 `git cat-file blob` 原样字节（execSync 别 trim）；② commit message **末尾要带 `\n`**（GitHub API 不会自动补）；③ 日期给带 `+08:00` 偏移的 ISO；④ node execSync 走 cmd.exe，`^{tree}` 的 `^` 会被吃掉，用 `git show -s --format=%T` 代替。
- **事故**：当时有另一个并行会话在同一工作区做同样的推送，远端出现重复的文章提交 + 它自己的 works.ts 版本。处理：内容以远端为准（文章/封面 blob SHA 验证一致），`git fetch + reset --hard origin/main` 对齐，本地游离提交放弃。**多会话同仓操作前先 `git log origin/main` 对一下远端指针。**
