### 环境坑：代理间歇性 502

本机环境有 HTTP 代理 `http://127.0.0.1:61473`（env 里 http_proxy/https_proxy），
**直连 github.com 不通，必须走代理**；但代理会间歇性返回 `CONNECT tunnel failed, response 502`。
解决办法是**重试**（实测第 2 次基本就成功）。以后在本仓库执行 git push / 访问 GitHub，
都用重试循环包一层，不要一次失败就判断为不可达。
注意：`api.github.com` 比 `github.com` 稳定得多，查状态优先用 API。
