# 2026-10-16

## 个人博客大重构：VitePress → React SPA

把 GitHub 仓库 `blue-riband-x/personal-blog`（原 VitePress 博客「妄想龙王的世界」）
重构进本地工作空间 `D:/coding/Blog-X`（原为 SENTINEL AI 企业安全落地页模板）。

技术决策：
- 保留本地 React + Vite + TS + Tailwind 作为基底，VitePress 侧只迁移「内容」，不保留 VitePress。
- 文章继续用 Markdown + frontmatter 维护，放在 `src/content/posts/*.md`，
  通过 `import.meta.glob(..., { query: "?raw", import: "default", eager: true })` 构建期收集。
- frontmatter 解析自己写了 ~30 行极简解析器（**未用 gray-matter**，因为它依赖 Buffer，浏览器端会出问题）。
- 渲染用 `react-markdown` + `remark-gfm`；文章正文样式自己在 `index.css` 里写 `.prose-blog`（未引入 typography 插件）。
- 路由 `react-router-dom` v7，basename 取 `import.meta.env.BASE_URL`，
  `vite.config.ts` 里 base 按 mode 切换：生产 `/personal-blog/`，开发 `/`。
- GitHub Pages 子路由回退：`scripts/spa-404.mjs` 在 build 后把 index.html 复制成 404.html（配 `postbuild`）。

新增/改写文件：
- 新增 `src/lib/posts.ts`、`src/lib/site.ts`、`src/vite-env.d.ts`
- 新增 `src/pages/`：Home / BlogList / BlogPost / About / NotFound
- 新增 `src/components/Footer.tsx`，改写 Navbar（含移动端菜单）、HeroSection
- 新增 `.github/workflows/deploy.yml`、`scripts/spa-404.mjs`
- 删除遗留脚手架 `app.config.ts`、`public/manus-routes.json`
- 改写 `index.html`、`TODO.md`、`public/favicon.svg`

环境注意：
- 本机**没有 pnpm，也没有 gh CLI**，用 npm 10.9.2 + node 22.22.2 装依赖（已生成 package-lock.json）。
- 仓库默认分支 `main`，Pages 已开启，但工作空间还不是 git 仓库，推送需用户自己执行。

验证：`npm run build` 通过（tsc -b 无错），dev 下 `/`、`/blog`、`/blog/first-post` 均 200；
用 `vite.createServer().ssrLoadModule()` 验证过 frontmatter 解析结果正确。
