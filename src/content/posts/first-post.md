# 🚀 第一篇博客 — 启程

这是我的个人博客的第一篇文章。

## 为什么建这个博客？

一直想有个地方记录自己的学习和成长。技术路上一路走来，踩过不少坑，也有不少收获。写下来既能帮助自己梳理思路，也许还能帮到后来人。

## 博客打算写什么？

- **技术分享** — 前端、后端、系统设计等领域的实战经验和踩坑记录
- **思考随笔** — 对技术趋势、产品设计和职业发展的个人看法
- **项目记录** — 自己折腾的各种项目，从想法到落地的全过程

## 技术栈

这个博客基于 **VitePress** 构建，使用 GitHub Pages 免费部署。

VitePress 的优点：

- 📝 Markdown 写文章，专注内容
- 🚀 基于 Vite，开发体验极快
- 🎨 支持 Vue 组件，可深度定制
- 📦 纯静态站点，部署简单

## 未来计划

- 持续更新博客内容
- 添加更多个性化定制
- 探索更多前端技术
