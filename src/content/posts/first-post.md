# 🚀 第一篇博客 — 启程

这是我的个人博客的第一篇文章。

## 为什么建这个博客？

一直想有个地方记录自己的学习和成长。技术路上一路走来，踩过不少坑，也有不少收获。写下来既能帮助自己梳理思路，也许还能帮到后来人。

## 博客打算写什么？

- **技术分享** — 前端、后端、系统设计等领域的实战经验和踩坑记录
- **思考随笔** — 对技术趋势、产品设计和职业发展的个人看法
- **项目记录** — 自己折腾的各种项目，从想法到落地的全过程

## 技术栈

这个博客基于 **React + Vite + Tailwind CSS** 构建，文章用 Markdown 写在仓库里，通过 GitHub Pages 免费部署。

这么搭的好处：

- 📝 Markdown 写文章，内容归内容，样式归样式
- 🚀 Vite 冷启动和热更新都很快，改完立刻能看到效果
- 🎨 全站由组件拼装，想改哪块改哪块，不怕牵一发动全身
- 📦 纯静态产物，省钱、省心、速度快

## 未来计划

- 持续更新博客内容
- 添加更多个性化定制
- 探索更多前端技术
